# Miyao Seminar

Create a professional, modern, responsive, high-converting landing page for an in-person Brazilian Jiu-Jitsu seminar with João Miyao.

The seminar will take place in Blumenau, Santa Catarina, Brazil, on October 22 at 7:00 PM.

IMPORTANT:
All development instructions, component names, variables, code structure, comments, and technical implementation must be written in English.

All visible website content must be written in Brazilian Portuguese.

The website must be designed specifically to maximize seminar registrations.

MAIN GOAL

Convert visitors into paid registrations.

The page should be built mobile-first because most traffic will come from:

Instagram
Facebook
WhatsApp
Meta Ads

Within the first few seconds, visitors must immediately understand:

Who João Miyao is
What the event is
When it happens
Where it happens
Why they should attend
How to register

Create a premium martial arts visual identity focused specifically on Brazilian Jiu-Jitsu.
